# Student Grade Management System

A simple Python project for managing student records and grades using lists and dictionaries.

## Why This Is Useful

This project is useful because it helps you:

- Store student information in one place
- Track grades for different subjects
- Calculate average marks quickly
- View a full student report at any time
- Add or remove records when needed
- Manage a small classroom or academic record system without a database

It is a practical beginner-friendly solution for handling academic data in a simple way.

## When to Use It

Use this project when:

- You want to manage a small number of students
- You need to store subject-wise grades
- You want to calculate averages for individual students
- You are learning Python basics such as loops, dictionaries, and functions
- You need a simple command-line tool for classroom record management
- You do not need a full database-backed system yet

This is ideal for small classrooms, student projects, and learning exercises.

## Features Used

- Add a new student
- Prevent duplicate student IDs
- Add grades for a student
- Validate grades between 0 and 100
- Calculate average grades
- Display a student report with all grades
- List all registered students
- Remove a grade or a student
- Use a menu-based interactive console system

## How to Run It

1. Open your terminal or command prompt.
2. Go to the project folder.
3. Make sure Python is installed.
4. Run the following command:

```bash
python student_grade_management_system.py
```

## Simple Workflow Example

1. Add a student with an ID, name, and class.
2. Add grades such as Math, Science, or English.
3. View the student report to check all recorded marks.
4. Calculate the average grade for the student.
5. Remove a grade or student if necessary.

## Use Cases

- School or classroom record keeping
- Student grade tracking for small groups
- Beginner Python practice projects
- Academic reporting demos
- Learning about data storage with Python dictionaries and lists

## Notes

This project stores data in memory while the program is running. It does not save data permanently after the program exits, so it is best for learning and small temporary use cases.
