# Expense Tracker

A simple Python project for recording and managing daily expenses.

## Why This Is Useful

This project is useful because it helps you:

- Track daily and monthly spending
- Organize expenses by category
- Monitor total spending over time
- Review spending by type such as food, bills, or entertainment
- Remove incorrect or outdated entries
- Keep personal finances simple without using a database

It is a practical and beginner-friendly tool for managing day-to-day budget records.

## When to Use It

Use this project when:

- You want to track personal or household expenses
- You need a simple budget summary
- You want a command-line application without extra setup
- You are practicing Python file handling and JSON data
- You need a lightweight tool for everyday expense management

This is ideal for personal budgeting, small finance tracking, and learning projects.

## Features Used

- Add a new expense with description, category, and amount
- Validate that the amount is positive
- Store data in a local JSON file
- View all recorded expenses
- Show total spending summary
- Display category-wise totals
- Delete an expense from the list
- Use a menu-based interactive console application

## How to Run It

1. Open your terminal or command prompt.
2. Go to the project folder.
3. Make sure Python is installed.
4. Run the following command:

```bash
python expense_tracker.py
```

## Simple Workflow Example

1. Add an expense such as groceries.
2. Enter the category like `food`.
3. Add the amount spent.
4. View all expenses to review the list.
5. Check the summary to see total spending and category totals.
6. Delete any incorrect entry if needed.

## Use Cases

- Personal budgeting
- Household expense tracking
- Daily spending records
- Learning JSON file storage in Python
- Beginner Python project for finance management

## Notes

This project stores expense data in a local `expenses.json` file, so the information remains available after the program closes. It is best for small personal budgeting and learning, not large-scale financial systems.
